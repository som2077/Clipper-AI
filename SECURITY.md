# Security Policy

## Reporting Security Issues

We take the security of Clipper AI seriously. If you discover a security vulnerability, please bring it to our attention immediately.

### Responsible Disclosure Guidelines
- **Do not** disclose vulnerabilities publicly until they have been addressed.
- Provide detailed steps to reproduce the issue (proof of concept, curl commands, screenshots, or logs).
- Allow a reasonable amount of time for the team to investigate and remediate the issue before any public announcement.

### Supported Versions
Only the latest release on the `main` branch is actively supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

### Contact
Please send security reports directly to:
- **Email:** `security@clipper.ai`
